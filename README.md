PEPTIDE & FITNESS TRACKER V2 — UNIVERSAL WEB APP

How to install:
1. Upload this folder to Netlify, GitHub Pages, or any static hosting service.
2. Open the site on iPhone using Safari.
3. Tap Share > Add to Home Screen.
4. The app saves data locally on each user's device.

Universal features:
- Settings/Profile screen
- Custom user name, plan title, age, height, units
- Starting weight, goal weight, protein, water, sleep, and vial-use-limit days
- Custom peptide/reminder list with editable schedule days
- 90-day daily tracker generated from each user's settings
- Dose calculator for U-100 syringe units
- Vial inventory with use-by alerts
- Workout editor
- Nutrition template
- Progress log

Important:
This app is an organization tracker only. It is not a prescription, diagnosis, or medical advice.
All peptide dosing and medical decisions should be reviewed with a licensed clinician.
